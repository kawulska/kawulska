## Lung Cancer Prediction

A machine learning project focused on predicting lung cancer diagnosis from clinical patient data. The workflow includes exploratory data analysis, handling missing values, feature engineering, and comparing multiple classification models.

![Python](https://img.shields.io/badge/Python-informational?style=flat) ![scikit-learn](https://img.shields.io/badge/scikit-learn-informational?style=flat)  ![Jupyter](https://img.shields.io/badge/Jupyter-informational?style=flat)

**Key features:**
- Exploratory Data Analysis (EDA) with visualizations
- Comparison of multiple models: Random Forest, SVM, Logistic Regression
- Evaluation metrics: AUC-ROC, confusion matrix, precision/recall

**Tech stack:** Python, scikit-learn, pandas, Jupyter

[Lung Cancer Prediction](https://github.com/kawulska/Machine-Learning-in-Python/tree/main/ClassificationProject)

## Fashion Analysis – Shiny App

An interactive Shiny application that tracks and analyzes daily outfits over one month. Users log clothing items each day, and the app generates statistics on the most worn colors, clothing categories, and outfit combinations.

![R](https://img.shields.io/badge/R-informational?style=flat) ![Shiny](https://img.shields.io/badge/Shiny-informational?style=flat) ![ggplot2](https://img.shields.io/badge/ggplot2-informational?style=flat) ![computer vision](https://img.shields.io/badge/computer_vision-informational?style=flat)

**Key features:**
- Day-by-day outfit logging and categorization
- Color frequency charts and palette analysis
- Interactive dashboard built with Shiny

**Tech stack:** R, Shiny, ggplot2, computer vision

[Fashion App](https://github.com/kawulska/Data-Visualization-Techniques-in-R/tree/main/Aplikacja%20Modowa)
